# Checklist

## Before collecting

- [ ] One-sentence question.
- [ ] Rule file written, and every script reads it.
- [ ] Questions tagged `measured`, `control`, or `brand`.
- [ ] Three or more controls.
- [ ] Calibration passed: every engine parses, controls hold.
- [ ] Budget gives a useful minimum detectable rate.

## Each report

- [ ] Method before numbers.
- [ ] Equal readings per engine per question.
- [ ] Controls and brand questions held out of every rate.
- [ ] Search reported apart from chat.
- [ ] Every rate shows numerator, denominator, raw n and effective n.
- [ ] Minimum detectable rate shown next to every comparison.
- [ ] Blind spots listed.
- [ ] Rule file unchanged since last run, or the run is labelled a new baseline.
