# Checklist

## Before building

- [ ] One writer, one channel, one format.
- [ ] Five or more samples marked `use`.
- [ ] Two or more held-out samples, never shown to the build step.
- [ ] Rights to use every sample.

## Profile

- [ ] Every trait has a number or a list, and one quoted example.
- [ ] Held-out samples mostly match.
- [ ] Version and digest at the top.

## Each review

- [ ] Names the profile version and digest.
- [ ] Four reports, kept apart.
- [ ] Every voice finding quotes the sentence and names the trait.
- [ ] Every claim has a source or is marked `unsourced`.
- [ ] Approval is `waiting` unless a person signed off.
