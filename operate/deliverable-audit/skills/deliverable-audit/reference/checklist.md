# Checklist

## Report counts

- [ ] Products in scope.
- [ ] Total ratings.
- [ ] Written reviews.
- [ ] Bare ratings (unreadable).
- [ ] Delivery complaints (written).
- [ ] Links fixed and verified (all three checks).
- [ ] Links still missing, with reason.
- [ ] Replies drafted.

## Each fix

- [ ] Fixed at the source, not only sent to one customer.
- [ ] Opens logged out.
- [ ] Right file type.
- [ ] Right, current content.

## Before publishing anything about the audit

- [ ] No customer names, emails, order IDs or review text.
- [ ] No revenue figures.
- [ ] Counts match `inventory.csv`.
