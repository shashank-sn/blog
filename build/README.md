# build

shipping code with a coding agent. these workflows are for engineers and technical founders who want fewer regressions and reviews that catch the right things. each one adds a gate where agents usually skip a step, and keeps the evidence that the gate held.

- **[most coding-agent failures are skipped stages](delivery-loop/README.md)**  
  the agent builds before anyone agreed on what to build, or says "tests pass" about an old commit. an eleven-stage loop where every gate leaves evidence. skill: `delivery-loop`
